# SheetMapper

SheetMapper 是一款纯 Swift、完全本地运行的 macOS 表格映射工具。它可将基础表每一行的数据按用户建立的映射写入 XLSX 模板，并选择每行一个文件或每个工作簿包含多个数据 Sheet。

## 主要功能

- 图形化选择基础字段和模板单元格。
- 自定义每个工作簿包含的 Sheet 数量。
- 直接修改原始 XLSX 包中的映射单元格，保留模板样式和打印设置。
- 保存常用映射；文件名或 Sheet 名变化后仍可按结构识别。
- 工作表按需预览，生成时读取完整有效数据。
- 文件仅在本机处理，不依赖 Node.js 或浏览器服务。
- 支持简体中文与英文，首次跟随系统语言，手动切换后自动记忆。

## 编译运行

1. 使用 Xcode 打开 `SheetMapper.xcodeproj`。
2. Scheme 选择 `SheetMapper`，运行目标选择 `My Mac`。
3. 点击运行。

首次编译需要联网下载 ZIPFoundation。系统最低版本为 macOS 13。

## 文件兼容性

- 原生支持 `.xlsx`。
- `.xls`、`.et`、`.ett` 需要本机存在兼容的转换程序。
- 不支持受密码保护或加密的工作簿。

## 隐私提示

程序不会上传工作簿。公开提交问题时，请勿附带真实姓名、证件号码或银行业务数据，应使用能够复现问题的虚构样本。
