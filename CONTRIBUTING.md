# Contributing

Contributions are welcome.

1. Create a focused branch from `main`.
2. Keep workbook processing local and avoid adding telemetry or network uploads.
3. Add or update synthetic tests for behavior changes.
4. Run both Debug and Release builds plus the `SheetMapperTests` executable.
5. Never commit real customer, banking, identity or business workbooks.

Bug reports involving spreadsheets should include a minimal synthetic workbook and the exact macOS/Xcode versions.
